# 🤝 Contributing to AI Resume Builder

Thank you for considering contributing to this project! We appreciate your time and effort. Here's how you can help.

---

## 📋 How to Contribute

### 1. Fork the Repository
Click the **Fork** button at the top-right of this page to create your own copy.

### 2. Clone Your Fork
```bash
git clone https://github.com/<your-username>/ai-resume-builder.git
cd ai-resume-builder
```

### 3. Create a Feature Branch
```bash
git checkout -b feat/your-feature-name
```

### 4. Make Your Changes
- Follow the existing code style and conventions
- Write clear, concise commit messages (see below)
- Test your changes locally before pushing

### 5. Commit with Conventional Commits
```bash
git commit -m "feat: add resume template selector"
git commit -m "fix: resolve PDF export alignment issue"
git commit -m "docs: update installation instructions"
```

### 6. Push & Open a Pull Request
```bash
git push origin feat/your-feature-name
```
Then open a **Pull Request** on GitHub with a clear description of your changes.

---

## 🧭 Commit Convention

We follow [Conventional Commits](https://www.conventionalcommits.org/):

| Prefix   | Description                     |
|----------|---------------------------------|
| `feat:`  | A new feature                   |
| `fix:`   | A bug fix                       |
| `docs:`  | Documentation changes           |
| `style:` | Formatting (no logic changes)   |
| `refactor:` | Code restructuring           |
| `test:`  | Adding or fixing tests          |
| `chore:` | Maintenance / tooling           |

---

## 🐛 Reporting Bugs

Open an [Issue](../../issues) with:
- Steps to reproduce
- Expected vs. actual behavior
- Screenshots (if applicable)
- Your environment (OS, browser, Node version)

---

## 💡 Suggesting Features

We love ideas! Open a [Feature Request](../../issues/new?template=feature_request.md) with:
- Problem you're solving
- Proposed solution
- Alternatives considered

---

## 📏 Code Style

- **Components:** PascalCase (`HomePage.jsx`)
- **Utilities & services:** camelCase (`claude.js`)
- **CSS Modules:** camelCase class names
- **Folders:** kebab-case
